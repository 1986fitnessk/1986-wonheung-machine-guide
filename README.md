# 1986 원흥점 머신 사용 가이드

블랙/차콜 + 아이보리 + 샴페인 베이지. HTML/CSS/JS 정적 사이트.

## 실행
이 폴더에서 `python3 -m http.server 8766 --bind 127.0.0.1 --directory dist` 실행 후 http://127.0.0.1:8766 접속. dist/index.html 직접 열기도 지원합니다.

1. T바 로우
2. 해머 플라이
3. 바이킹 프레스
4. 라이프 피트니스 앱도미널
5. 라이프 피트니스 트라이셉 익스텐션
6. 라이프 피트니스 바이셉 컬
7. 리니어 로우
8. 어시스트 풀업 · 딥스 (운동 안내 2종)
9. ISO-레터럴 와이드 체스트(해머)
10. ISO-레터럴 슈퍼 인클라인 프레스(해머)
11. ISO-풀오버(해머)
12. ISO-레터럴 디클라인 프레스(해머)

사용자 사진 순서와 팁을 보존했습니다. 배경 제거 머신 사진은 WebP로 제공하고, 원본 PNG도 dist/assets에 보관합니다. 기본 설정과 3단계 사용법의 출처는 CONTENT_SOURCES.md 및 각 상세 안내 하단에 있습니다. T바 로우와 바이킹 프레스는 정확한 실기 모델 설명서가 아닌 공통 동작 참고입니다.

## 확인
머신 28개·운동 안내 30종. 머신 이미지는 WebP, 마스코트는 투명 PNG 스프라이트입니다. 초보자 전신·상체·하체 및 중급자·상급자 루틴은 준비 중 화면입니다. 최신 실제 검사 및 한계는 REVIEW.md와 SECURITY.md를 확인하세요. 검색 회귀 검사: `node tests/search.test.cjs dist/app.js`. 별도 빌드 과정 없음. 공개 사이트: https://1986fitnessk.github.io/1986-wonheung-machine-guide/

저장소: https://github.com/1986fitnessk/1986-wonheung-machine-guide

공통 QR에는 위 공개 사이트 주소를 사용합니다.

## GitHub Pages 배포
공개 소스에는 서비스 파일과 누끼 처리된 머신 사진만 포함하며 원본 사진, 로컬 검수 화면, 비밀정보는 제외합니다.

`main`은 소스, `gh-pages`는 `dist` 배포 결과입니다. 변경 후 커밋하고 `sh deploy.sh`를 실행합니다. GitHub CLI 인증 및 저장소 쓰기 권한이 필요합니다. 출처는 각 머신 상세의 참고 자료에서도 확인할 수 있습니다.
